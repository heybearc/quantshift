# What's New in Version 1.21.0

**Released:** November 25, 2026

---

## ✨ New Features

### Watch a symbol

Symbols now includes a library of US stocks and crypto names. Pick one, or type a name such as NVDA or BTC-USD, and watch it for this session.

**What you can do:**
- See the latest price, bid, and ask
- Follow a session graph that keeps moving with the quote
- Add the name to your book

**How to use it:**
1. Open **Symbols**
2. Choose a name from the library, or type one and choose **Watch**
3. Choose **Add to book** if you want to keep it

Watching a quote does not place an order.

### Research a symbol

Research pulls recent headlines and the trend for the name you are watching, so you can decide whether it belongs on a book.

**What you can do:**
- See whether the name is rising, falling, or flat
- Compare the day, week, and month
- Read the high, low, volume, and headlines

**How to use it:**
1. Open **Symbols** and choose a name
2. Choose **Research**
3. Read the brief, then add the name to your book if you want it

Research does not place an order. The house books keep their own symbol list.
