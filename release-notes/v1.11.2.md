# What's New in Version 1.11.2

**Released:** October 10, 2026

---

## 🐛 Bug Fixes

### Live and standby label stays current

The dashboard label that shows whether you are on the live site or the standby site was keeping the answer from the last release. After a release it could say standby while you were on the live site.

**What this means for you:**
- The label now checks the current routing each time you load it
- Live and standby match the site you are actually using
