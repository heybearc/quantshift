# What's New in Version 1.18.1

**Released:** October 16, 2026

---

## 🐛 Bug Fixes

### A signed-in session stays signed in

Leaving the dashboard open no longer ends in a red “Failed to fetch bot status” banner. The session renews while you are using the app. When the session is actually over, QuantShift signs you out and returns you to the sign-in screen.

---

## 💡 What You Need to Know

- If the dashboard is already showing that banner, sign in again once after this update
- After that, an open dashboard keeps your session
- Paper trading is unchanged
