# What's New in Version 1.18.7

**Released:** October 27, 2026

---

## 🐛 Bug Fixes

### Kraken can take over from the standby host

The standby machine can now start the Kraken paper book if the primary machine goes quiet. Equity and Coinbase were already covered. One book going quiet no longer moves the others.
