# What's New in Version 1.12.1

**Released:** October 10, 2026

---

## 🐛 Bug Fixes

### Optimization page shows real results

Strategy results on the Optimization page now come from stored trades. If accuracy has not been measured yet, the page says so instead of showing a made-up score.

### Invitation email is sent

Accepting an invitation now sends the same verification email as a new registration. The account is still created if the mail service is unavailable.

### Missing news no longer changes a trade size

If headlines cannot be loaded, the bot treats sentiment as neutral. It no longer scores sample headlines, so a news outage does not change how large a trade is.

### Menu button no longer covers the title

On a phone, the menu button sits at the top right of the screen.

---

## 🔒 Security Improvements

### Database password stays on the server

The trading service no longer keeps a database password inside its program files. The server supplies that setting when the service starts.

---

## 💡 What You Need to Know

- No action is required
- Kelly position sizing stays off
- Older open trades still have a blank reason until the next fill
