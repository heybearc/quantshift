# What's New in Version 1.19.1

**Released:** November 9, 2026

---

## 🐛 Bug Fixes

### Sign-in works for an API client

A successful login now returns the bearer token. A rejected sign-in shows the reason from the server.

### Kraken can trade again after a quiet day

The daily-loss breaker no longer stays shut after the book has recovered or a new day has started. Restarting Kraken or the sprint book keeps the closed-trade result instead of refilling the account from $5,000.
