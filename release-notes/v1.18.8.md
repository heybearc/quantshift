# What's New in Version 1.18.8

**Released:** November 6, 2026

---

## ✨ New Features

### A quiet hour explains itself

When Coinbase or Kraken stays flat, the dashboard says why. You can see how many names were checked, how many had no squeeze, and how many had no pivot break.

---

## 🐛 Bug Fixes

### Finished trades now show up in performance

A closed paper trade is saved as closed. Performance counts those finished trades for equity, Coinbase, and Kraken. The result curve uses that closed result. Estimated fill cost stays beside the result and is not taken from the account.

The paper window started again on November 6, 2026. The earlier window did not keep a record of closes, so it is not part of this score.
